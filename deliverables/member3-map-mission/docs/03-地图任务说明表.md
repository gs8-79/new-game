## 1. 任务总表

| 任务类型 | 枚举 | 出发命令 | 现场允许的动作 | 结算方式 | 载货来源 |
| --- | --- | --- | --- | --- | --- |
| 资源采集 | `MissionKind::Gather` | `mission <资源>` / `出任务 食物\|木材\|石料\|草药\|兽皮` | `move`、`gather`（仅本次指定资源，食物任务可顺带采兽皮）、建设/结算 | 回营地或已建前哨 `settle` | 现场采集 |
| 前哨建设 | `MissionKind::OutpostConstruction` | `mission outpost` / `出任务 前哨` | `move`、`build outpost`、`settle`；**`gather` 被拒绝** | 在新建前哨或营地 `settle` | 出发时从仓库带走木材 6、石料 4 |

两种任务共用同一张十六地点地图、同一套行动规则与同一份消耗表；差别只在“载货从哪来”和“能不能采集”。

## 3. 消耗表：每条地图动作的代价

| 动作 | 命令 | 回合 | 队长疲劳 | 队员疲劳 | 资源/载货变化 | 其他 |
| --- | --- | --- | --- | --- | --- | --- |
| 移动 | `move <编号\|名称>` | +1 | +2 | +1 | 无 | 目标必须相邻；首次进入标记“新地点已发现” |
| 采集 | `gather <资源>` | +1 | +4 | +2 | 载货 +（见上表），采集时段 +1（上限 4） | 地点不支持或与指定资源不符则拒绝 |
| 建造前哨 | `build outpost` | +1 | +5 | +3 | 木材 −6、石料 −4（只能来自随队载货） | 该地点成为结算点；营地与已建前哨处拒绝 |
| 结算 | `settle` | +1 | +1 | +1 | 载货与任务背包交给上层入账 | 全员经验 +`15 + 10×采集次数`；凝聚力 +2；阶段变为 Settled |
| 攻击遭遇 | `attack` | +1 | +4 | +2 | 敌军生命 −`max(2, 力量/2 + 敏捷/4)` | 队长生命 −`max(1, 5 − 耐力/4)`（不低于 1） |
| 防御遭遇 | `defend` | +1 | +2 | +1 | 无 | 队长生命 −`max(1, 3 − 耐力/5)`（不低于 1） |
| 撤退遭遇 | `retreat` | +1 | +2 | +1 | 无 | 位置固定回到 8 古老山隘；遭遇清零 |
| 使用草药 | `use <草药>` | +1 | 0 | +1 | 载货草药 −1 | 队长生命 +18（不超过上限）、疲劳 −20 |

> 所有疲劳增量都夹在 0 至 100 之间（`ExpansionGame::recordTurn`）。回合只在**已成功提交**的动作上推进；被拒绝的命令既不改状态也不推进回合（交付测试逐字段校验）。

## 6. 结算点规则（重点核查项）

`settle` 是资源进入部落仓库的**唯一入口**，这条规则由三层共同保证：

| 层 | 行为 | 证据 |
| --- | --- | --- |
| 地图层 | `settle` 只把阶段改为 `Settled` 并保留载货；**从不写部落库存** | `expansion_game.cpp` `settle`（注释“保留载货和背包给上层 GameEngine 统一入账”） |
| 引擎层 | 只有当地图阶段为 `Settled` 时，才把 `cargoFood/Wood/Stone/Herbs/Hides` 与任务背包一次性并入库存，然后清空活动任务 | `game_engine_mission.cpp` `executeMission` 的 settled 分支 |
| 放弃路径 | `abort` 直接丢弃载货、`missionCount` 不增加、稳定度 −2，仓库不增加任何资源 | `game_engine_dispatch.cpp` `dispatchMissionCommand` |

合法与非法结算点：

| 情形 | 结果 |
| --- | --- |
| 在 1 燧火营地结算 | 成功（营地永远是结算点） |
| 在自建前哨结算 | 成功，并在该地点驻留（下次任务从该处出发） |
| 在其他未建前哨的地点结算 | 拒绝：“这里只能停留；请在营地或已建前哨结算。” |
| 结算后再执行 `settle`/`move`/`gather`/`build outpost`/`attack`/`defend`/`retreat`/`use` | 全部拒绝：“任务已结算。” |
| 未结算就 `abort` | 载货丢弃，仓库不变（`missionCount` 不变） |

## 7. 失败矩阵（什么时候会被拒绝）

| 场景 | 触发命令 | 拒绝原因（玩家看到的提示） | 状态是否改变 |
| --- | --- | --- | --- |
| 跨越地图跳点 | `move 7`（营地→矿场） | 两地不相邻，不能跨越道路移动。 | 否 |
| 原地停留 | `move 1`（已在营地） | 小队已经在这里。 | 否 |
| 未知地点 | `move 17` / `move 不存在的` | 未知地点；输入地图可查看1至16号地点。 | 否 |
| 地点不产该资源 | `gather stone`（在苍林） | 当前地点没有这种资源。 | 否 |
| 混采 | `gather food`（本次指定木材） | 本次任务由指定资源队执行，不能混采。 | 否 |
| 载货已满 | `gather wood`（载货 = 容量） | 小队载货已满，请结算。 | 否 |
| 采集时段用尽 | 第 5 次 `gather` | 本次任务的采集时段已用完，请前往营地或前哨结算。 | 否 |
| 建设任务中采集 | `gather wood`（建设任务） | 前哨建设任务只能运输建材，不能额外采集。 | 否 |
| 材料不足 | `build outpost`（木材 < 6 或石料 < 4） | 建造前哨需要现场携带木材6、石料4。 | 否 |
| 营地建前哨 | `build outpost`（在营地） | 营地无需建造前哨。 | 否 |
| 重复建前哨 | `build outpost`（已有前哨） | 该地点已经有前哨。 | 否 |
| 要塞未击退就建前哨 | `build outpost`（岩牙要塞） | 岩牙要塞仍有敌对巡逻，不能建造前哨。 | 否 |
| 错误地点结算 | `settle`（未建前哨处） | 这里只能停留；请在营地或已建前哨结算。 | 否 |
| 非要塞的遭遇指令 | `attack` | 这里没有可攻击的遭遇。 | 否 |
| 无遭遇时的防御/撤退 | `defend` / `retreat` | 当前没有遭遇战。 | 否 |
| 遭遇期间的其他指令 | `move` / `gather` / `settle` / `build outpost` / `use` | 岩牙巡逻拦住道路；只能攻击、防御、撤退或查看。 | 否 |
| 草药不足 | `use 草药`（载货草药 0） | 任务载货中没有草药。 | 否 |
| 结算后继续行动 | 任意地图命令 | 任务已结算。 | 否 |
| 行动点用尽时出发 | `mission wood`（行动点 0） | 本季小队行动点已经用完，请结束回合。 | 否 |
| 劳力不足时出发 | `mission wood`（木材队 0 人） | 该资源队至少需要分配2名劳力；先用 assign/分配 配置。 | 否 |
| 仓库建材不足时出发 | `mission outpost`（木材 5） | 前哨建设任务需要从仓库带走木材6、石料4。 | 否 |
| 疲劳过高时出发 | `mission wood`（小队疲劳 ≥ 85） | 晨火队过于疲劳，需要先休整。 | 否 |

> 上表每一行都有对应测试；覆盖矩阵见 `05-测试说明与验收矩阵.md`。

## 8. 任务状态字段速查（`ExpansionState`）

| 字段 | 含义 | 取值/上限 |
| --- | --- | --- |
| `phase` | 任务阶段 | `Exploring`（可行动）/ `Settled`（已结算） |
| `turn` | 任务回合，每个成功动作 +1 | ≥ 0 |
| `worldLocation` | 当前地点（0 至 15，对应编号 1 至 16） | 必须已发现 |
| `worldDiscovered[16]` | 已发现地点；`[0]` 恒为 true | 布尔数组 |
| `outposts[16]` | 结算点；`[0]` 恒为 true（营地） | 布尔数组 |
| `cargoFood/Wood/Stone/Herbs/Hides` | 现场载货 | 各项 ≥ 0，合计 ≤ `cargoCapacity` |
| `cargoCapacity` | 载货上限 | `16 + crewSize × 4` |
| `harvestActions` | 已用采集时段 | 0 至 4 |
| `missionKind` / `assignedResource` | 任务类型与指定资源 | 枚举 |
| `crewSize` | 随队劳力 | 2 至 6 |
| `encounterLife` / `encounterDefeated` | 岩牙巡逻血量与击退标记 | 仅要塞可非 0；击退后必须为 0 |
| `backpack` | 任务背包（容量 80 重量 / 20 格） | 与仓库、人物装备三者互斥 |
| `settled` | 结算标记 | 必须与 `phase == Settled` 一致 |

> **持久化警告**：`ExpansionState` 的字段顺序与数量被 v6 存档格式锁定（`save_codec.cpp` 的 `writeExpansionState`/`readExpansionState`）。新增字段必须同时提升 `kSaveVersion` 并改写编解码，否则老存档读取会错位。本次交付的所有优化都刻意**不新增持久化字段**。
