# 页面与架构

## 原型落地

依据工作区根目录的 `12.rp`：居中封面、下方选项、独立存档与帮助页面。原型仅提供页面结构，采用终端可显示的 ASCII 篝火与山形图案实现封面。正常游戏提供快速8季、正式16季、长期32季三种长度。

```text
封面 ── 开始游戏 ── 模式选择 ── 游戏面板
     ├─ 读取存档 ── 七档列表 ── 读取后进入游戏
     ├─ 游戏帮助 ── 六类帮助
     └─ 退出
游戏 ── 经营 / 十六地点小队地图 / 战争 / 结局 / 沙盒
     ├─ 保存或读取
     ├─ 帮助（返回原进度）
     └─ 返回封面或退出（先自动保存）
```

## 边界与数据流

`main` 初始化终端后调用 `runApplication(input, output, saveRoot, interactive, ansiEnabled, terminalWidth)`。注入流和存档目录便于测试完整流程。页面导航使用循环，不递归启动新应用。

`GameEngine` 拥有一份 `GameState`，处理中文、英文和数字命令。规则验证后提交候选状态；失败不会消耗行动或修改进度。`ConsoleUI` 只读状态，渲染标题、模式/季节、部落、资源、外交、当前局面、消息和阶段命令。

`ExpansionGame/ExpansionState` 是唯一的十六地点小队地图实现。主游戏部署长期小队；采集任务在地图地点装载资源后，必须在营地或前哨结算才会回写部落仓库。前哨建设任务从仓库带走6木材、4石料，再在地图现场建造。装备只能处于仓库、人物、任务背包或军队锁定位置之一。旧苍林路线、常驻任务和旧存档迁移均不保留。

`SaveRepository` 负责文件读写和七档摘要。`inspect()` 返回 `SaveSummary`，只读解析主档/备份/临时文件，不调用带恢复副作用的 `load()`。只有玩家选择档位才读取并恢复。文件不可访问时不选旧备份，以免误读较旧进度。

## 终端显示

默认读取可见终端宽度，下一次页面刷新重新查询；测试可固定宽度。UTF-8按码点计列，中文与全角标点占两列，常用组合符不占列，样式转义不计宽度。所有页面输出先缓冲后折行，不从UTF-8字节中间截断。推荐至少80列、30行；小窗口可以滚动阅读。

篝火使用橙色，资源按类别着色，外交使用友好/中立/敌对色，警告使用黄色。重定向时关闭ANSI和动画，支持脚本输入。页内分类和长说明使用B/Enter返回；游戏内操作仍输入命令后按Enter。

## 注释约定

用短注释解释不明显的原因：加载前验证、原子替换、只读检查、任务复用及中文折行。避免注释复述单行代码。公开名称使用 `GameEngine/GameState/GameMode/GamePhase/GameEnding/TribeId/SaveRepository/SaveSlot`，不保留版本后缀或兼容别名。
