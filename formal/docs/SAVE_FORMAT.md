# 存档格式与恢复

## 文件

脚本运行时目录为项目根目录，存档放在 `saves/game`：`slot1.sav` 至 `slot6.sav`、`autosave.sav`。文件的本地修改时间用于列表显示，复制文件可能改变该时间。当前格式为 v7；v5/v6 及更旧文件不会迁移或改写，读取时提示需要新开局。

头部为8字节 `TRIBESAV` 标识、32位格式版本、32位负载长度、32位校验和。当前格式版本为7；数值采用小端序，字符串带长度，数量与总文件大小有上限。格式版本是文件协议标识，不是玩家侧的游戏模式。完整状态包含五种资源、人口上限、统一人口池的待重分配标记、劳力与住房岗位、共享装备仓库、部落/派系、小队驻地、16地点发现与前哨、前哨守卫、人物、可选活动任务及其任务类型/资源类型、任务位置/载货/疲劳/任务背包、占领驻军、战争锁定装备及工艺战力、季度事件队列及当前序号、负责人、结局、编年史以及 `nextItemSerial`。后者为全局递增的制造序号，使装备在装备、携带或报废后仍不会重用同季编号。

## 写入与读取

保存：校验状态 → 序列化 → 内存往返校验 → 写入.tmp并校验 → 主档轮换为.bak → .tmp替换主档。替换失败时尝试恢复主档，并保留错误信息。手动覆盖需在应用层确认。

读取：主档有效时优先读取；主档缺失/损坏时依次尝试 `.bak`、`.tmp`。有效的 v7 候选必须先成功恢复主档，才会交给游戏；恢复落盘失败时当前游戏不变。主路径不是普通文件或暂不可访问时停止，不自动回退。所有候选均失败则当前游戏不变。

旧版本策略：v5/v6 与更旧版本不自动迁移，读取时明确提示需要新开局；原文件和调用方游戏状态均保持不变。非法 UTF-8、ASCII 控制字符（包括 ESC）或 ANSI 转义序列会在读取、替换状态和保存前统一拒绝。

## 列表状态

- Empty：主档与两个候选均缺失。
- Ready：主档完整有效。
- Recoverable：主档缺失/损坏，至少一个候选有效。
- Corrupt：档案不可读取，且不满足上述可读取条件。

列表中的时间和摘要来自将被选用的那个文件，展示模式、阶段、季节进度、部落、当前首领、人口及食物/木材/石料/草药。浏览不会创建目录、修复主档或更新文件时间。
