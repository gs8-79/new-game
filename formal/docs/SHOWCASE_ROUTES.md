# 试玩路线

1. 双击开始正式版.cmd，确认封面和下方四项菜单；窗口缩到40列，再拉到100列，下一次页面应按新宽度排版。
2. 选择3帮助，查看2经营建设和3探索小队；B返回目录，再B返回封面。
3. 选择1开始游戏，再选2正式游戏。输入3采集食物、4采集木材、保存 1。
4. 再次保存 1并输入n，确认取消覆盖；输入读取 1恢复进度。
5. 输入5进入苍林。尝试移动 苍林、移动 深林、采集 草药、回营；查看状态、人物和资源变化。
6. 输入back回到封面；选择2读取存档，查看A自动档与手动档1的时间和资源摘要；输入A继续。
7. 输入quit，确认退出前保存。另开一次游戏，分别选择快速与长期模式核对季节。
8. 固定复现：封面输入seed quick 7，后续操作和随机结果可按相同输入复现。

战争、派系AI、五结局、装备和伤亡的自动回归见测试程序。不要把某次试玩或自动测试等同于课堂验收与Mac实机验证。
