# 软件测试报告

## 1. 测试环境

- Windows x64
- Visual Studio 2026 / MSVC 14.51
- CMake、Ninja、CTest
- C++17，`/W4 /permissive- /utf-8`

## 2. 测试方法

- 单元测试：直接调用规则引擎、战术和存档接口，验证单个规则。
- 路线测试：从新游戏开始只执行正常命令，完成五类结局和快速模式。
- 失败测试：构造资源不足、错误前置、损坏存档和非法数值，检查状态不变。
- 回归测试：每次构建同时运行原有三个 Demo 的全部测试。
- 人工烟雾测试：启动 Release 程序，检查中文、整屏布局、数字/双语输入和保存读取。

## 3. 自动测试覆盖

- 九地点连接、六建筑、九技术、22种事件定义。
- 正式/快速初值、事件种子可重复、季节与人口小队数。
- 数字/中文/英文等价命令和未知命令。
- 资源失败原子性、探索门槛、建筑唯一性、技术前置。
- 三部落两阶段任务、关系、岩牙停战。
- 四种战术、第三年冬季敌袭和战斗伤亡边界。
- 联盟、征服、繁荣、迁徙、覆灭五类结果及结束后禁止修改。
- 三个手动档、自动档、损坏存档和事件表篡改。
- 无 ANSI 环境的纯文本界面。

## 4. 最终结果

- 2026-08-25 完整 Debug 构建：CTest 2/2 通过；旧 Demo 33/33，正式版 25/25。
- 2026-08-25 完整 Release 构建：CTest 2/2 通过；旧 Demo 33/33，正式版 25/25。
- Release 交互烟雾测试通过：`quickseed 6` 能进入快速模式；数字、中文和英文命令均生效；彩色资源、阵营颜色、清屏重画和底部命令栏显示正常。
- 手动档烟雾测试通过：保存档1后修改资源，再读取档1，资源和剩余小队恢复到保存时状态。
- 自动档烟雾测试通过：进入下一季后修改资源，再读取自动档，恢复到该季开始状态。
- Windows ZIP 解压后，独立运行 `tribe-dawn.exe` 可显示中文主菜单并正常退出。
- 源码 ZIP 已检查文件完整性和 Windows/macOS 脚本；当前机器的 Visual Studio 安装器在独立构建复验期间更新工具并要求重启，因此 `TRIBE_FORMAL_ONLY=ON` 仍需在重启后补跑。完整构建已经编译相同的正式版源码并通过25项测试。
- macOS 脚本已做静态检查；本机不是 macOS，仍需要组内 Mac 同学执行一次真实构建。
