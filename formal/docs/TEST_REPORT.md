# 当前玩法验证记录

当前版本为 v5：玩法闭环为“十六地点地图探索 → 五种资源回营或前哨结算 → 统一人口池分配 → 装备、外交、战争与占领 → 四类可预测季节事件”。v4 存档不迁移，必须新开局。

## 自动测试

`tribe-formal-tests` 当前注册 10 项回归用例：

1. 玩家界面显示五种资源、地图功能标签，以及首季任务后的三条道路进展。
2. 五种资源均可参与以物易物；贝币相关贸易和任务命令不再生效。
3. v5 存档可往返保存活动采集任务与前哨建设任务；v4 被明确拒绝。
4. 统一人口池会拒绝超额组军或派遣小队。
5. 组军、解散军队、战争胜利后的自动释放、据点驻军和受训战士互斥正确。
6. 人口损失后进入劳力待重分配状态，只能先降低岗位或驻军。
7. 工坊负责人职业校验、装备品质、实际属性加成与最多 `+4` 工艺战力正确。
8. 医者负责人职业校验、治疗、休整与卸任正确。
9. 难民与疾病两类事件的两条选择及资源代价正确。
10. 勒索与派系诉求两类事件的两条选择、建筑减伤/增益和失败原子性正确。

失败操作通过 v5 完整存档快照比较，确认不会悄然修改资源、人物、任务、库存、外交或季节状态。
