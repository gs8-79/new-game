# 软件测试报告

## 1. 测试环境

- Windows x64
- Visual Studio 2026 / MSVC 14.51
- CMake、Ninja、CTest
- C++17，`/W4 /permissive- /utf-8`

## 2. 测试方法

- 单元测试：直接调用规则引擎、战术和存档接口，验证单个规则。
- 路线测试：从新游戏开始只执行正常命令，完成五类结局和快速模式。
- 失败测试：构造资源不足、错误前置、损坏存档和非法数值，检查状态不变。
- 回归测试：每次构建同时运行原有三个 Demo 的全部测试。
- 人工烟雾测试：启动 Release 程序，检查中文、整屏布局、数字/双语输入和保存读取。
- 扩展路线测试：从营地分别走通和平贸易与固定种子战斗、拾取、回营。

## 3. 自动测试覆盖

- 九地点连接、六建筑、九技术、22种事件定义。
- 正式/快速初值、事件种子可重复、季节与人口小队数。
- 数字/中文/英文等价命令和未知命令。
- 资源失败原子性、探索门槛、建筑唯一性、技术前置。
- 三部落两阶段任务、关系、岩牙停战。
- 四种战术、第三年冬季敌袭和战斗伤亡边界。
- 联盟、征服、繁荣、迁徙、覆灭五类结果及结束后禁止修改。
- 三个手动档、自动档、损坏存档和事件表篡改。
- 无 ANSI 环境的纯文本界面。
- 扩展V1的人物成长、八栏装备、背包、小队、疲劳、队长阵亡、双语和平路线、三段战线、撤退、拾取与固定种子。
- 扩展V2的8/16/32季、16地点、六部落、永久小队、贸易与贝币、派系危机、首领更替、战争、五种结局和长期沙盒。
- V2的6个手动档、1个自动档、全状态往返、校验和、损坏拒绝及`.bak/.tmp`恢复。
- 五种结局各5帧ASCII、颜色与静态回退、后日谈、编年史和重放。
