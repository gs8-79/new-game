# 当前玩法验证记录

当前版本为 v7：玩法闭环为“十六地点地图探索 → 按人数派遣并回营或前哨结算 → 统一人口池与最多7点行动力 → 建筑、研究、装备、外交、战争与占领 → 每季至少两个、风险季最多三个事件”。住房建筑提高人口上限并需配置住房岗位；长屋未维护时会产生稳定惩罚。v5/v6 及更旧存档不自动迁移，必须新开局且原文件不改写。

## 自动测试

`tribe-formal-tests` 当前注册 31 项回归用例：

1. 玩家界面显示五种资源、地图功能标签，以及首季任务后的三条道路进展。
2. 五种资源均可参与以物易物；贝币相关贸易和任务命令不再生效。
3. v7 存档可往返保存人口上限、住房岗位、季度事件队列、活动采集任务与前哨建设任务；v5/v6 被明确拒绝且原文件不变。
4. 统一人口池会拒绝超额组军或派遣小队，资源任务必须显式指定正人数。
5. 组军、解散军队、战争胜利后的自动释放、据点驻军和受训战士互斥正确。
6. 人口损失后进入劳力待重分配状态，只能先降低岗位或驻军。
7. 工坊负责人职业校验、装备品质、实际属性加成与最多 `+4` 工艺战力正确。
8. 医者负责人职业校验、治疗、休整与卸任正确。
9. 难民与疾病两类事件的两条选择及资源代价正确。
10. 勒索与派系诉求两类事件的两条选择、建筑减伤/增益和失败原子性正确。
11. 地图任务拒绝非相邻道路和错误地点资源，且失败不移动、不消耗采集次数。
12. 地图载货到达上限后拒绝继续采集，保留已装载资源。
13. 前哨建设仅消耗现场木材和石料，并将地点变为可结算点。
14. 岩牙要塞遭遇期间阻止移动，撤退后回到相邻山隘。
15. 地图资源只有在营地结算后才进入部落仓库。
16. 七个空档位均显示为空档；读取失败不覆盖调用方当前状态。
17. 自动档和六个手动档均可独立保存、检查和读取。
18. 主档损坏时可从有效备份或临时文件恢复。
19. 脚本化应用流程覆盖“封面→新局→采集→结算→保存→读取→返回→退出”，并使用系统临时目录。
20. 手动存档覆盖会要求确认，取消后保留原档。
21. 80 列与 24 列终端渲染均保持有效 UTF-8 且关闭 ANSI 时不输出转义序列。
22. 同季制造装备在转移到人物后仍使用全局递增编号，不会与新制造物冲突。
23. 地图草药使用会真实推进一个任务回合，并保持生命、疲劳和载货结算一致。
24. `replaceState` 拒绝非法 UTF-8、控制序列、非法物品枚举和不一致的任务遭遇，且不污染原状态。
25. 固定随机种子命令序列的每一步均保持合法；失败或无状态变更命令与前一份二进制快照完全相同。
26. 长屋建成后提升人口上限，配置住房并完成季末结算时增加人口；未配置住房时施加稳定惩罚。
27. 季末事件按队列逐个处理，未完成前禁止经营和结束季节；风险季度可生成第三个事件。
28. v7 存档字段可完整往返保存；旧 v5/v6 文件、损坏文件和携带控制字符的文件均被拒绝，不覆盖调用方状态。
29. 资源任务的零人数参数被拒绝，失败不消耗行动力。

失败操作通过 v7 完整存档快照比较，确认不会悄然修改资源、人物、任务、库存、外交或季节状态。
