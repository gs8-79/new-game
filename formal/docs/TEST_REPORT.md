# 当前玩法验证记录

当前版本只保留“十六地点地图探索 → 劳力分工 → 装备库存 → 军队与占领 → 季末事件”的玩法循环。旧苍林独立路线、常驻任务、旧命令和旧存档迁移均不在测试范围内，也不再受支持。

## 自动测试

`tribe-formal-tests` 当前包含 9 项回归用例：

1. 经营界面的直接采集、侦察与旧数字资源入口不会改变状态。
2. 仅可在相邻地点移动；资源队限制、采集与安全结算正确，失败操作保持原子性。
3. 前哨建设材料、守卫分配和无人前哨荒废正确。
4. 武备工坊制造、人物装备转移和损坏装备维修正确。
5. 军队锁定真实库存装备；胜利后可占领并受驻军上限限制。
6. 医者维护、草药治疗和任务内草药使用正确。
7. 季末待决事件会阻止其他行动，直到玩家选择。
8. 当前格式存档会完整保存活动任务，并明确拒绝旧版本存档。
9. 快速、正式、长期三种模式均从第一季开始，长度分别为 8、16、32 季。

失败操作通过当前格式的完整存档快照比较，确认不会悄然修改资源、人物、任务、库存、外交或季节状态。
