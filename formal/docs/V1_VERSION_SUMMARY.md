# 大型扩展 V1 版本总结

版本：`v1.0.0-expansion-preview`

定位：可试玩的苍林狩猎纵切，不替代旧正式模式。

## 本版完成

- 修复守卫防御提前清零、岩牙战力归零后征服锁死和非法战术崩溃。
- 保存失败时保留当前局，可重试、另存或取消；损坏主档可从有效备份恢复。
- 加入具名角色、八项属性、经验、等级、成长点、疲劳、忠诚和休整。
- 加入八栏个人装备、完好/损坏/报废状态、重量与背包格限制。
- 支持2至8人作业小队、队长和成员自动跟随；已建立常驻任务字段与军队基础类型，自动结算和军队玩法留到V2。
- 主菜单输入 `e` 可试玩苍林狩猎；`expanded <2至8>` 可选择人数。
- 支持和平交谈与贸易、主动劫掠、三段战线战斗、军令、撤退、免费拾取和回营结算。
- 主要操作同时支持中文和英文，固定种子可完全重现。

## 试玩路线

和平路线：

```text
e
move forest
move deep
gather herbs
move clearing
talk
trade
return
```

战斗路线：

```text
expandedseed 113 4
move forest
move deep
move clearing
raid
order focus
attack
```

突破三段战线后输入 `loot`，再输入 `return`。
