# 正式版与大型扩展V2测试计划

## 1. 自动测试

- 新游戏：正式和快速模式初值、季节、地图、固定剧情位置正确。
- 命令：数字、中文、英文、空白、连续空格、ASCII 大小写和未知命令。
- 原子失败：资源不足、错误目标、重复建筑、技术前置不足、未相邻侦察均不改变状态。
- 季节：人口对应小队数、食物消耗、冬季加成、饥荒、士气和覆灭。
- 地图：九个地点的连接、发现顺序和地点资源门槛。
- 建筑技术：六种建筑唯一性、九项技术前置与效果。
- 外交：三个部落的交谈、赠礼、两阶段任务、关系上限、停战与联盟条件。
- 事件：相同种子事件表相同，不同种子至少一项不同；保存读取后不改变事件。
- 战斗：四种战术、侦察伏击、撤退、胜负边界、伤亡和营地耐久。
- 结局：五种结局、多个可选结局、覆灭优先、结束后禁止修改。
- 存档：四个槽位往返、缺字段、额外字段、重复键、非法数字、错误版本和写入失败。
- V2战役：快速8季、课程16季、长期32季及非覆灭结局后继续沙盒。
- V2世界：16地点、六部落自主行动、首领更替、永久小队、常驻任务、疲劳和精锐经验。
- V2外交与内部：贸易供需、贝币、联姻、朝贡、索贡、战争、停战、派系抗命和政变。
- V2存档：6个手动档、1个自动档、全状态往返、校验和、非法状态、损坏档和`.bak/.tmp`恢复。
- V2结局：五种各5帧ASCII、颜色与静态回退、后日谈、人物、编年史和重放命令。
- 回归：现有三个 Demo 的 33 项测试继续通过。

## 2. 人工测试

- Visual Studio 2026 Debug/Release 构建与 CTest。
- Windows 终端中文标题、颜色、清屏、底部命令和输入光标。
- 终端宽度不足或输出被重定向时退回无颜色滚动模式。
- 正式模式至少完成联盟、征服、繁荣、迁徙路线各一次。
- 快速模式在15分钟课堂演示中覆盖建设、外交、战斗、保存和读取。
- V2固定种子路线覆盖双语命令、存档恢复、8季上限、迁徙结局、重放和编年史。
- 真实交互终端检查V2彩色结局动画；当前自动烟测只验证无等待的静态回退。
- 在 macOS 上按说明执行 CMake 构建和启动脚本。
