# 小组成员分工模板

请在提交课程报告前将姓名、学号和实际完成内容补充完整。即使代码由同一份仓库集成，每位成员也应理解并讲解自己负责的模块。

| 成员 | 学号 | 主要职责 | 对应成果 | 个人测试 |
|---|---|---|---|---|
| 待填写 | 待填写 | 组长、需求和版本集成 | WBS、用例、Git提交与最终构建 | 完整回归 |
| 待填写 | 待填写 | 地图与经营 | 地点、资源、季节、建筑 | 地图与资源测试 |
| 待填写 | 待填写 | 外交与事件 | 部落关系、任务、事件表 | 外交事件测试 |
| 待填写 | 待填写 | 战斗与结局 | 战术策略、敌袭、五种结局 | 战斗结局测试 |
| 待填写 | 待填写 | 界面、存档与文档 | 主界面、命令、存档、说明 | 存档与人工测试 |

## 协作约定

- 每项功能先写清输入、输出和失败条件，再修改代码。
- 每次提交只包含一个主题，提交前运行相关测试。
- 不直接删除他人改动；发生冲突时由模块负责人共同确认。
- 报告中的分工以实际 Git 记录、测试记录和课堂讲解为准。
