C++ MUD 选题试玩集
===================

一、开始方法

1. 请先完整解压 ZIP，不要直接在压缩包里运行。
2. 双击“开始试玩.cmd”。
3. 输入 1、2、3 选择一个 Demo。
4. 进入游戏后输入 help 或 帮助 查看命令。

公共命令：

help / 帮助    查看帮助
save / 保存    保存当前游戏
load / 读取    读取当前游戏
back / 返回    返回选择菜单
quit / 退出    退出程序

三、评分

试玩三款游戏后，可打开 EVALUATION.md，按照玩法吸引力、课程契合度、
实现风险和扩展潜力进行评分。

存档会自动保存在程序旁边的 saves 文件夹中。
